# IA Nery - Assistente de Apoio ao Cuidador Informal

Bem-vindo ao repositório do projeto **IA Nery**, uma plataforma desenvolvida para auxiliar e oferecer suporte a cuidadores informais através de inteligência artificial.

🌍 **Acesse a aplicação em produção:** [https://ia-nery.vercel.app/](https://ia-nery.vercel.app/)

---

## 🚀 Como executar este projeto localmente?

Se você deseja trabalhar localmente usando a sua própria IDE (como o VS Code), você pode clonar este repositório e executar a aplicação na sua máquina. O único requisito é ter o [Node.js e npm instalados](https://github.com/nvm-sh/nvm#installing-and-updating).

Siga os passos abaixo:

\`\`\`sh
# Passo 1: Clone o repositório usando a URL do projeto
git clone <URL_DO_SEU_REPOSITORIO>

# Passo 2: Navegue até o diretório do projeto
cd <NOME_DO_DIRETORIO_DO_PROJETO>

# Passo 3: Instale as dependências necessárias
npm install

# Passo 4: Inicie o servidor de desenvolvimento
npm run dev
\`\`\`

O servidor será iniciado com auto-reloading. Acesse `http://localhost:8080` (ou a porta indicada no terminal) para visualizar a aplicação.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando um ecossistema moderno para desenvolvimento web:

- **Vite** (Bundler e ambiente de desenvolvimento rápido)
- **TypeScript** (Tipagem estática para JavaScript)
- **React** (Biblioteca para construção de interfaces de usuário)
- **shadcn/ui** (Componentes de interface acessíveis e customizáveis)
- **Tailwind CSS** (Framework de estilização utilitária)
- **Supabase** (Backend as a Service - Autenticação e Banco de Dados)

## 🤖 Como editar este código?

**Diretamente no GitHub:**
- Navegue até os arquivos desejados.
- Clique no botão "Edit" (ícone de lápis) no canto superior direito.
- Faça as alterações e realize o commit.

**Usando GitHub Codespaces:**
- Na página principal do repositório, clique em "Code" (botão verde).
- Selecione a aba "Codespaces" e clique em "New codespace".
- Edite os arquivos diretamente no ambiente do navegador, faça o commit e o push quando terminar.
